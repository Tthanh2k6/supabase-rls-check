# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text is at that link. It applies to issues, pull requests, discussions and any other project space.

To report a conduct problem, use the private advisory form at https://github.com/Tthanh2k6/supabase-rls-check/security/advisories/new, or send a message to a moderator in GitHub Discussions. This is a one-person project, so reports are handled on a best-effort basis.
